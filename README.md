# Azure Virtual Machine Provisioning using Terraform

# Overview
This project demonstrates how to provision an **Azure Virtual Machine** using **Terraform** following **Infrastructure as Code (IaC)** principles.  
The project was developed as an individual academic project during my MCA 3rd semester.

It focuses on automating infrastructure creation in a secure, repeatable, and version-controlled way

# Tools & Technologies
- Terraform
- Microsoft Azure
- Git & GitHub
